dji-action1-importer
一个关于把第三方视频改成大疆action1可以识别视频的程序
DJI Action 1 反向导入工具

> 把电脑上的视频导入到大疆 Action 1 相机里，在相机屏幕上直接播放

---

背景

官方没有提供反向导入功能，这个工具填补了这个空白。

我自己有一台 Action 1，想把剪好的视频导回相机里播放，但全网都找不到工具。折腾了一天，用 Claude AI 写了一个，居然跑通了，分享出来给大家用。

---

使用方法

先把四个文件转移到一个文件夹中下载ffmpeg把ffmpeg.exe / ffprobe.exe也放在这个文件夹里然后在这个文件夹里新建两个子文件夹，比如叫“待导入转换”和“转换结果”。把你想批量导入相机的所有第三方视频都丢进“待导入”文件夹里，支持mp4/mov/mkv/avi等常见格式。“结果”文件夹不用预先建文件，程序会自动创建。
打开命令行并定位到该文件夹
​​在主地址文件夹栏输入cmd回车（Mac使用语句cd过去），确保命令行当前路径就在转换这个文件夹里，可以先输入dir（Mac用ls）看一下不能看到刚才去的文件。
运行批量命令
输入： python3 batch_dji_graft.py --ref DJI_0819.MP4 --input-dir待至 --output-dir 结果 --start 900 （Windows上python3不行就换python）。--start 900 表示输出文件从 DJI_0900.MP4开始往后面编号，先看一下卡里现有文件最大编号是多少，把这个数字改成继续往后排的。回车后会自动依次转换文件夹里每个视频，实时显示进度条。
查看结果
处理完毕后会打印汇总：成功几个、失败几个。如果有失败的会列出具体文件名和错误信息，其余成功的不继续。“转换结果”文件夹里此时已经是一排DJI_0900.MP4、DJI_0901.MP4...这样按序号命名好的文件了。
批量进入SD卡
把“转换结果”文件夹里所有成功的文件整批复制进相机SD卡的DCIM目录下
---

依赖安装

需要安装 Python 3.8+
下载地址：https://python.org

需要安装 ffmpeg
下载地址：https://www.gyan.dev/ffmpeg/builds/

下载后把 ffmpeg.exe 放到项目文件夹里的 ffmpeg/bin/ 目录下
