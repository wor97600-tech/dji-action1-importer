# DJI Graft 桌面界面
技术：Python Tkinter/ttk，无 Tailwind 或额外运行依赖。浅色扁平风格。
主色保留原应用绿色，灰阶与主色梯度通过 refactoring-ui 生成。
一级：输入/输出、开始转换；二级：编码与进度；三级：帮助及日志。唯一填充主按钮是开始转换。
左侧文件及批量命名、右侧编码设置及日志、固定底部操作。默认全部设置可见，按工作区缩放。
间距 4/8/12/16/24/32/48，组间大于组内。两种字重，三种中性文字等级。
同一几何图形生成 SVG/PNG/ICO，窗口和 EXE 共享图标。
模式路径独立、输入校验、重复执行保护、运行锁定、覆盖确认、关闭保护。
原界面 P0：主操作被纵向堆叠挤出（§2.1 / §3.2）。双栏和固定底栏解决。

## 验证（2026-10-24）
- 1080×700、920×630、1280×760 的单视频/批量模式共六组布局，关键控件均在客户区内；模式路径记忆、运行锁定通过。
- 八组文字/背景对比度均达到普通文字 4.5:1 要求。
- 29 项自动测试：26 通过，3 项因缺少原始样片跳过。真实 GUI 的 AMD 短片转换、封面处理、完成状态和输出入口通过。
- 对比改版前 GUI 的 AST，_worker / _run_single / _run_batch 完全一致。
- 窗口版轻量 EXE 构建、FFmpeg 环境自检和启动通过。未在此次 UI 修改后重新进行实体相机测试。
- 自动桌面截图受工具授权限制，未完成截图视觉复核；布局验证以真实 Tk 控件边界为依据。

## 5.0 正式版修正
- 旧布局检查仅判断窗口边界，遗漏了父容器裁切。复现确认批量模式中画质和说明超出左栏；将编码区移到右栏，六组布局现已通过逐级父容器边界检查（包含说明、环境按钮和日志按钮）。
- 默认自动选择显卡、码率上限 2000 kbps（2 Mbps），界面明确说明 CPU 回退、CRF 适用范围和码率留空含义。
- 次级按钮采用绿色描边、浅绿底、加粗文字与按下/悬停状态；日志操作明确标为“复制日志”“保存日志”。
- 正式 EXE 版本资源为 5.0.0.0，产品版本 5.0。默认自动显卡真实转换成功，本机依次检测后使用 AMD AMF；保持原有转码与容器处理方法。
