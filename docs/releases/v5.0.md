# DJI Graft v5.0 · Windows 正式版

此次仅更新 Windows；Android 保留 v4.0.0，不发布新 APK。源码沿用 MIT 许可开放。

## 下载与运行

下载 DJIGraft-5.0-Windows-x64.exe，适用于 Windows 10/11 x64，单文件约 12.5 MB，不需要安装 Python，未内置 FFmpeg。已有 FFmpeg/ffprobe 可直接使用，缺少时程序提供检测与准备。校验值见附件 SHA256SUMS.txt。

## 更新内容

- 全新扁平双栏界面，固定底部开始按钮，修复批量模式下画质和码率说明遮挡。
- 默认自动检测 NVIDIA NVENC → Intel Quick Sync → AMD AMF；检测、编码或校验失败时尝试后续编码器，全部失败回退 CPU。也可手动选择。
- 默认码率上限 **2000 kbps（2 Mbps）**；留空跟随参考视频，CRF 只用于 CPU 编码与回退。
- 修复相机封面使用参考视频、紫绿颜色异常和误识别照片的问题，使用输入视频预览原位等长替换。
- 完善 AMD / NVIDIA 相机播放兼容性，保留既有转码与容器移植流程。
- 消除 FFmpeg 黑色控制台弹窗及反复闪烁。
- 统一应用图标，强化按钮辨识，新增日志复制/保存、输入校验、覆盖确认和运行锁定。

## 验证说明

本地回归测试 26 项通过、3 项因样片缺失跳过；6 组布局检查通过，默认显卡真实转换通过。AMD / NVIDIA 已收到相机回放通过反馈；Intel QSV 仍需对应设备实测。硬件加速依赖显卡、驱动和 FFmpeg 支持，建议先用短片验证封面、声音与播放，再批量导入。
