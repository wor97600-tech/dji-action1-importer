# DJI Graft v5.1 · Windows 正式版

这是 Windows 桌面版的 v5.1 独立发布。Android 手机版继续保持 v4.0.0，本次不修改手机端，也不发布 APK。

## 本次更新

- 批量模式选择文件夹后建立任务队列，按原视频文件名自然排序。
- 队列显示原视频、输出文件名、状态和“单独转换 ▶”操作。
- 可编辑单行输出文件名；可单独转换某一项；全部任务结束后可重试失败视频。
- 队列区域随窗口缩放，滚动条正常跟随内容。
- 等待、完成和失败状态用不同颜色显示，默认编号从 `DJI_0000.MP4` 开始。
- 前缀或起始编号修改会统一更新队列中的输出名称。
- 单项操作会显示转换中、完成、重试等状态；悬停时高亮，窗口按钮带短颜色过渡。
- 整批转换会跳过已完成且输出文件仍存在的视频，并在列表中提示跳过数量。

## 转换兼容性

本版本保留 v5.0 的 CPU、自动显卡、NVENC、QSV、AMF、封面生成、容器移植和相机兼容处理逻辑。手机端保持 Android v4.0.0。

## 下载

下载 `DJIGraft-5.1-Windows-x64.exe`，Windows 10/11 x64 可直接运行。程序不内置 FFmpeg，首次转换时会自动准备运行环境。
