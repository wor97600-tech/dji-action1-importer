# DJI Graft v5.3 · Windows 正式版

## 相比 v5.2 新增与改进

- **更新队列**：队列上方新增简约刷新图标，点击原地平滑旋转，重新读取文件夹；保留已有顺序、手动文件名及外部拖入的视频，新文件追加到末尾。
- **拖入 MP4**：支持从资源管理器拖入一个或多个 MP4，同一文件不会重复添加。队列中有视频即可转换，无需先填写输入文件夹；未设置输出位置时默认使用首个拖入视频目录下的 `DJI_Output`。
- **手动调整顺序**：每行新增上下排列的 ▲、▼，直接点击即可移动。自动输出编号跟随队列顺序，手动修改过的文件名保持不变。
- **单独转换排队**：转换一个视频时可继续点击其他视频加入等待队列，按点击顺序依次执行；正在转换或已排队的视频不能重复加入，某项失败后继续处理后续任务。已完成的视频可再次转换，覆盖已有输出前明确确认。
- **完成当前后停止**：立即取消当时所有等待任务并恢复状态，当前视频完成后停止；仍可立即重新添加其他视频排队，新任务会在当前视频完成后继续执行。
- **扫描与拖放稳定性**：仅加入可读、容器结构有效且包含视频轨道的 MP4；已有文件暂时不可读时保留原条目，避免误判为新增。修复 Windows 拖入视频导致闪退的问题，并检查输出及临时文件路径，避免覆盖原视频或参考视频。
- **队列显示优化**：切换深浅主题时排序区域立即同步；修复深色模式下五列表头悬停发白、文字不清楚，以及“排序”标题显示不完整的问题。
